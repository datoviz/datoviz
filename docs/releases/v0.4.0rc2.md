# Datoviz v0.4.0rc2

v0.4.0rc2 is the active release candidate and a narrow replacement for RC1. It fixes the packaged
macOS native-window Vulkan-loader mismatch while preserving the v0.4 architecture and API scope.

## Publication status

RC2 wheels are undergoing final validation and are not yet published. After publication, install
the exact package with:

```sh
python -m pip install --pre datoviz==0.4.0rc2
```

Until then, build `v0.4-dev` from source for native-window testing. The published RC1 macOS wheel
retains the native-window limitation recorded in the [RC1 release notes](v0.4.0rc1.md).

## Validation scope

RC2 requires fresh hosted build, wheel, clean-install, shader, consumer, and rendering evidence for
all six wheel targets. Hosted Linux also exercises the installed Quickstart through Xvfb, while
hosted macOS uses offscreen MoltenVK proof because hosted desktop-window sessions are unreliable.

The exact canonical macOS arm64 wheel must additionally pass an attended native-window Quickstart
on the available MacBook M3, including resize, pan, and zoom. Physical Linux and Windows hosts are
unavailable for this candidate and are recorded as explicit exclusions, not passes. Their physical
coverage returns for RC3 and the final release.

Final run identifiers, artifact checksums, TestPyPI evidence, and publication links will be added
only after those gates pass.
