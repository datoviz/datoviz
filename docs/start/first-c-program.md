# First C Program

This page will become the first complete v0.4 C walkthrough.

Start from a minimal native example while the tutorial prose is being finalized:

- source: `examples/c/visuals/point.c`
- validation: `just build` and `just test scene`


## Intended Shape

The final page should show a complete C program that:

1. creates a scene;
2. creates a figure and panel;
3. adds one retained visual;
4. presents it through `app` or renders it offscreen;
5. destroys owned objects in the documented order.

Do not use old v0.3 Pythonic plotting APIs in v0.4 examples.
