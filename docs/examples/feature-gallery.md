# Feature Gallery

This page indexes focused C examples for public scene/app features. It is a source-facing catalog
until gallery cards and screenshots are generated from `examples/c/MANIFEST.yaml`.

| Area | Sources |
| --- | --- |
| Scene and panels | `scene_basic.c`, `panel_single.c`, `panel_grid.c`, `panel_multi.c`, `panel_linked.c`, `panel_background.c` |
| Fields and scales | `sampled_field_2d.c`, `sampled_field_3d.c`, `colormap_scale.c`, `colorbar.c`, `legend_categorical.c` |
| Axes and adornments | `axes_2d.c`, `axis_labels.c`, `scalebar.c`, `scalebar_units.c`, `annotation_readout.c`, `text_block.c`, `overlay_card.c` |
| Controllers | `panzoom_attachment.c`, `controller_arcball.c`, `controller_fly.c`, `controller_turntable.c` |
| Picking and selection | `pick_point.c`, `pick_marker.c`, `pick_hover.c`, `image_probe.c`, `probe_labels.c`, `selection.c` |
| Updates and visibility | `update_visual_data.c`, `update_partial.c`, `visibility.c`, `timer_animation.c` |
| Materials and appearance | `mesh_texture.c`, `material_mesh.c`, `lighting.c`, `depth_test.c`, `alpha_blending.c`, `marker_symbols.c` |
| Media | `video_export.c` |

Feature sources live under `examples/c/features/` unless listed from `examples/c/workflows/`.
