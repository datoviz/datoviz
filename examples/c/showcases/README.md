# C Showcase Examples

Polished, composed, gallery-facing examples live here after they have scenario IDs, style metadata,
bounded smoke paths, and capture expectations. Synthetic, generated, and domain-flavored fake data
are allowed when stated clearly. Real-dataset examples with provenance belong in `../scientific/`.

Current public showcase seeds:

- `gpu_particle_smoke.c`
- `point_cloud.c`
- `textured_planet.c`
- `wind_field.c`
