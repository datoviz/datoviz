# C Showcase Examples

Polished, composed, gallery-facing examples live here after they have scenario IDs, style metadata,
bounded smoke paths, and capture expectations. Synthetic, simulated, generated, and real data are
allowed when stated clearly. Real-dataset examples need source, license, attribution,
preprocessing, and encoding metadata in `MANIFEST.yaml`.

Current public showcase seeds:

- `brain_volume_mesh.c`
- `choropleth.c`
- `gpu_particle_smoke.c`
- `linked_probe_colorbar.c`
- `panel_linked_axes.c`
- `point_cloud.c`
- `protein.c`
- `scalebar_measurement.c`
- `textured_planet.c`
- `wind_field.c`
