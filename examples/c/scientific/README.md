# C Scientific Examples

Real-data public examples belong here. A scientific example must record:

- dataset source and access URL;
- license, terms, citation, or attribution note;
- preprocessing command and prepared-data location;
- displayed encodings, units, and any simplifications;
- whether generated media may be redistributed.

Synthetic or generated domain-style examples belong in `../showcases/` instead.

Current public scientific examples:

- `protein.c`: RCSB PDB protein structure rendered as atom spheres.
