# Lab Examples

Non-public experiments, diagnostics, stress/perf demos, and migration source material live here.
Keep this folder flat. Files may remain buildable when useful, but they are not gallery-facing
unless promoted into `features/`, `visuals/`, or `showcases/`.

`gpu_particle_advection.c` is the experimental scene compute-to-graphics smoke proof. It
intentionally stays in lab until the scene compute API is classified for the public gallery surface.
