# Scene Core Specs

This directory contains the stable high-level scene contracts.

Read these files before changing scene ownership, runtime boundaries, figure/panel concepts, or the
pressure-test use cases that drive the rest of the scene spec.


## Files

1. [REQUIREMENTS.md](REQUIREMENTS.md): architectural requirements and required runtime services.
2. [OBJECT_MODEL.md](OBJECT_MODEL.md): stable scene concepts and ownership model.
3. [RUNTIME_BOUNDARY.md](RUNTIME_BOUNDARY.md): what scene may depend on and what stays below it.
4. [PANEL_LAYOUT.md](PANEL_LAYOUT.md): panel layout, margins, aspect, and figure composition.
5. [USE_CASES.md](USE_CASES.md): scenarios that pressure-test the spec.
