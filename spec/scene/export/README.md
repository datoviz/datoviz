# Scene Export Specs

This directory contains output-oriented scene behavior.

Use these files when changing image export, offscreen rendering semantics, panel-as-texture flows, or
the current vector-export scope decision.


## Files

1. [IMAGE_EXPORT.md](IMAGE_EXPORT.md): still image capture, render scale, and panel-as-texture.
2. [VECTOR_EXPORT.md](VECTOR_EXPORT.md): v0.4 decision to leave publication-oriented vector export
   to GSP/Matplotlib rather than Datoviz.
