# Scene Prototypes

This directory is reserved for temporary scene-spec prototypes that are too concrete for proposals
but not ready to become installed headers, tests, or examples.

Keep this directory empty unless a prototype has:

1. a clear owner or follow-up path,
2. an explicit status block,
3. a link to the normative or proposal document it is testing.

Prefer [../proposals](../proposals) for design notes and [../examples](../examples) for worked
example plans.
