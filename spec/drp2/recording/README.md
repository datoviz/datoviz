# DRP2 Recording Specs

This directory owns DRP2/DVZR recording and replay design notes.


## Index

1. [DVZR_PLAYER.md](DVZR_PLAYER.md): current recorder/player design, implemented slice notes, and
   future replay/export ideas.


## Boundary

The normative recording contract is DRP2-level: DVZR records timed DRP2 command streams and replay
metadata. Future API sketches, pacing loops, export paths, and packaging ideas in this directory are
design pressure, not active DRP2 `2.0` command requirements until promoted through
`../COMMANDS.md`, active schemas, and fixtures.
