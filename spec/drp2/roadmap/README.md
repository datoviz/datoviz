# DRP2 Roadmaps

This directory owns long-horizon DRP2 pressure notes that should not be mistaken for the active
`2.0` command contract.


## Index

1. [WEBGPU.md](WEBGPU.md): WebGPU feasibility, native/browser parity, and portability pressure.


## Boundary

Roadmap notes may explain why the active contract should remain portable, but they do not promote
commands, schemas, or conformance requirements on their own. Promote concrete protocol changes
through `../COMMANDS.md`, `../schema/`, and executable fixtures.
