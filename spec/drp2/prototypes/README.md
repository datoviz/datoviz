# DRP2 Prototype APIs

Files in this directory are exploratory API sketches for the future DRP2 surface.

They are not authoritative.
The source of truth is the markdown contract under `spec/drp2/`.

If a prototype conflicts with `LAYER1.md`, `ERRORS.md`, `CAPABILITIES.md`, or `VERSIONING.md`,
the markdown spec wins and the prototype should be rewritten or discarded.
